# Zorcha design instructions

Before creating or editing a design:

1. Read `DESIGN.md` and the relevant file in `patterns/`.
2. Choose exactly one surface contract: marketing or product.
3. Reuse the nearest template or example before introducing new structure.
4. Keep every factual image local under `assets/` and record its source in `SOURCES.md`.
5. Use honest empty states when live values are unavailable.
6. Run `npm test` before handing off.

Never infer a new Zorcha color, font, radius, or component pattern from taste alone. Evidence it from the Figma suite, `zorcha-website`, or `zorcha-frontend` and document the source.
